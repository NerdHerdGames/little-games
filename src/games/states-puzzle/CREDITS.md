# State boundary data

`source-topology.json` is the locally bundled `states-albers-10m.json` from
[us-atlas 3.0.1](https://github.com/topojson/us-atlas), downloaded from
https://cdn.jsdelivr.net/npm/us-atlas@3.0.1/states-albers-10m.json.

The boundaries derive from the U.S. Census Bureau's public-domain 2017
cartographic state boundary data. They use the Albers USA projection with
Alaska and Hawaii repositioned in insets. Coastlines are simplified; the map
is a learning puzzle, not a navigation reference. District of Columbia is
excluded because it is not a state. No network requests are made during play.

The puzzle's artwork, colors, and interface are generated locally from these
boundaries. us-atlas's redistribution license follows.
